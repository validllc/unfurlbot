# Contributing

Happy to take PRs. A few things that make them easy to merge:

- Run `npm run verify` first. CI runs the same thing and I won't merge red.
- New platform rows are the most useful contribution. Include a link that
  currently embeds badly and show that the proxy fixes it.
- Please don't add dependencies for things a few lines can do. The small
  dependency tree is a feature.

If you're not sure whether something is worth a PR, open an issue or ask on
the [support server](https://invite.unfurl.bot) first.
